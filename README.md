# CampusFlow

Asistente académico de escritorio para estudiantes: materias, tareas, horario, calificaciones, notas y un asistente de IA opcional.

**Sitio web:** https://chemaitas-boop.github.io/campusflow-app/

## Descarga

Última versión: **[CampusFlow-mac-arm64.dmg](https://github.com/chemaitas-boop/campusflow-app/releases/latest/download/CampusFlow-mac-arm64.dmg)** (beta 1.0.2)

- macOS 11 o superior, Mac con chip Apple (M1 o posterior). No hay versión para Mac con Intel.
- La app aún no está firmada por Apple: la primera vez, clic derecho sobre CampusFlow → *Abrir* → *Abrir*.
- Verificación opcional: `shasum -a 256 CampusFlow-mac-arm64.dmg` debe dar `058415c52092dfcf39ee1aa48304f0e6fc31ede0a6b3fa1f79c70dbcb177eb69`.
