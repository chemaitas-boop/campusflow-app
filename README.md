# CampusFlow

Asistente académico de escritorio para estudiantes: materias, tareas, horario, calificaciones, notas y un asistente de IA opcional.

**Sitio web:** https://chemaitas-boop.github.io/campusflow-app/

## Descarga

Última versión: **[CampusFlow-mac-arm64.dmg](https://github.com/chemaitas-boop/campusflow-app/releases/latest/download/CampusFlow-mac-arm64.dmg)** (beta 1.1.0)

- macOS 11 o superior, Mac con chip Apple (M1 o posterior). No hay versión para Mac con Intel.
- La app aún no está firmada por Apple: la primera vez, clic derecho sobre CampusFlow → *Abrir* → *Abrir*.
- Verificación opcional: `shasum -a 256 CampusFlow-mac-arm64.dmg` debe dar `dd955a05755457880519005072d4712ca349956dfe1aecb0f9f132df9ecc939a`.

## Asistente de IA (opcional)

Usa Google Gemini con tu propia clave gratuita de [Google AI Studio](https://aistudio.google.com/apikey). Requiere una cuenta de Google y ser mayor de 18 años. Con la capa gratuita, Google puede usar lo que escribas para mejorar sus productos; no escribas datos personales.

## Privacidad

Tus datos se guardan solo en tu Mac. Consulta la [política de privacidad](https://chemaitas-boop.github.io/campusflow-app/privacidad.html).
